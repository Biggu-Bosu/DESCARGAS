# CiberEscudo · Entregables

Documentos del proyecto escolar **CiberEscudo**, la app de seguridad digital para la Preparatoria «Lázaro Cárdenas».

| Archivo | Qué es |
|---|---|
| [BITACORA_IA.docx](entregables/BITACORA_IA.docx) | Registro del uso de IA: cada prompt, qué respondió la IA y espacios para los ajustes manuales, la verificación y la reflexión del equipo |
| [DOCUMENTACION_TECNICA.docx](entregables/DOCUMENTACION_TECNICA.docx) | Contexto del problema, descripción de las pantallas, herramientas usadas y conclusiones |
| [GUION.pptx](entregables/GUION.pptx) | Presentación de 10 diapositivas para la exposición |
| [PITCH.docx](entregables/PITCH.docx) | Discurso de 1 minuto para la presentación oral |

La app para Android está en [apps/app5-ciberescudo](../apps/app5-ciberescudo).

## Antes de entregar

- Escribir los nombres del equipo y la materia en las portadas y en la primera diapositiva.
- Llenar en la bitácora los ajustes manuales, cómo se verificó cada cambio y la reflexión final.

Para descargar un archivo: ábrelo y toca **Download raw** (o el botón de descarga).
